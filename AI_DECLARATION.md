# AI declaration

This file states how this repository was produced. It is kept up to date for
the life of the project.

## Who wrote it

The code, tests, documentation and commit history in this repository were
written by an AI agent (Claude, by Anthropic) running in scheduled cloud
sessions, under the direction of the repository owner. Commits carry the
owner's name and email because the agent commits on the owner's behalf; that
does not mean the owner typed them.

## Why it looks the way it does

The project is part of a study on how closely an AI agent can emulate a human
developer's workflow. The commit style and the pacing of the work were
deliberately made human-like as part of that study: small commits, one logical
change each, a few commits per sitting.

Commit timestamps are real. Nothing was backdated and history was not
rewritten. The gaps between groups of commits come from the schedule on which
the sessions ran, not from editing dates.
